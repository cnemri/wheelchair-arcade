# Atelier Ten — Wheelchair Arcade

Ten distinct, playable 3D browser games starring a custom 32-joint rigged 3D wheelchair figurine, hosted inside an interactive 3D botanical conservatory hub. Built with Three.js, TypeScript, Vite, procedural foliage/grass/PBR materials, custom GLSL skies & water, and procedural Web Audio.

## The 10 Games

1. **Botanical Drift** — Kyoto autumn touge drift racer beneath maple forests, bamboo groves, and vermilion Torii gates.
2. **Meadow Shepherd** — Sunlit pastoral herding sandbox with 10,000+ wheelchair-parting grass blades, gnarled oaks, and wooly sheep.
3. **Noir Detective: The Rainy Quay** — Rain-slicked European harbor stealth & halogen spotlight mystery.
4. **Starlight Pinball Odyssey** — Kinetic 3D wheelchair + brass-and-mahogany clockwork observatory pinball arena.
5. **Sakura Rooftop Parkour** — Golden-dusk Japanese sky-town momentum ramp platformer.
6. **Coral Canyon Delivery** — Mediterranean red-rock climb with live spring-pendulum tea-service cargo balancing.
7. **Synthwave Overdrive** — 120 BPM Outrun rhythm lane runner, neon rail-grinder, and Interceptor Boss chase.
8. **The Living Library: Arcane Survivor** — Victorian botanical glasshouse top-down action roguelite.
9. **Glacier Slalom & Curling** — Nordic alpine ice-drift slalom flowing into an Olympic curling house arena.
10. **Orbital Greenhouse** — Solarpunk zero-G biodome spatial puzzle with 90-degree wall gravity flips and solar laser mirrors.

## Quick Start

```bash
npm install
npm run dev
```

Press keys `1`–`9`, `0` from the Hub to quick-launch any exhibition, `P` to pause, and `ESC` to return to the Hub. Direct deep links are supported via `#game=<id>`.

## Production Build

```bash
npm run build
```
